My Project

School Event Check-In System

The School Event Check-In System is a Flutter application designed to help school organizers manage events, register attendees, and monitor attendance records efficiently.

The system provides a simple and organized way to manage school event participation through a digital check-in process.

Project Features

Organizer Login
Dashboard
Create Events
Guest Check-In
Attendance Records
Duplicate Prevention
Supabase Database
Logout

Technologies Used

Flutter, Dart, Supabase, Visual Studio Code, Git, and GitHub
