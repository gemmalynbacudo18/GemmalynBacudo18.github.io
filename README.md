# School Event Check-In System

## Project Description
School Event Check-In System is a mobile application developed using Flutter and Supabase. It helps school organizers manage events, register attendees, and monitor attendance efficiently.

## Features
- **Organizer Login** – Secure authentication using Supabase.
- **Dashboard** – Displays total events, attendees, and check-ins.
- **Create Event** – Add school events with dates, locations, and descriptions.
- **Guest Check-In** – Register students and record their attendance.
- **Duplicate Prevention** – Prevents duplicate student registration for the same event.
- **Attendance Records** – View attendance lists and check-in status.
- **Refresh and Logout** – Update records and securely sign out.

## Technologies Used
- Flutter
- Dart
- Supabase
- Visual Studio Code
- Git and GitHub

## Installation and Setup

1. Install Flutter SDK and Visual Studio Code.
2. Clone the repository:

   `git clone https://github.com/gemmalynbacudo18/GemmalynBacudo.github.io.git`

3. Open the project folder.
4. Install dependencies:

   `flutter pub get`

5. Run the application:

   `flutter run`

**Note:** An internet connection and properly configured Supabase backend are required.
